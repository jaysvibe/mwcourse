一台机器是怎么站起来的：看懂机械的五条命脉

这不是“波纹管课”，是“全才销售”的第一课。你以后卖的不是一个零件，而是客户机器里的一环。今天先学会：一台机器靠什么动、靠什么停、靠什么不散架。

第 1 课机械总览建议 60 分钟8 道自测1 个现场作业

先讲个真事。客户说“我们这台泵老是坏”，新手拎着样册去看泵；老销售先蹲下来看泵的底座、管道的支撑、联轴器的对中。因为泵本身可能没坏，是它“站的地方”先坏了。

机械销售最容易犯的错，是把自己卖的东西当成主角。客户买一台机器，不是买一堆零件，是买“能连续转、不出事、好修”。你要能在一台机器里，一眼看出：动力从哪来、经过什么传过去、最后干什么活、靠什么控制、靠什么支撑。这五条命脉看懂了，你卖什么都能接上话。

一、机器的五大部分：像人一样

任何一台机器，不管是一台水泵、一台机床、一条包装线，还是一台半导体设备，都可以拆成五部分：

部分干什么人身上的对应典型零件
动力提供能量心脏电机、发动机、气缸、液压泵
传动把能量送到该去的地方，改变转速/扭矩/方向血管、筋齿轮、皮带、链条、减速机、联轴器
执行真正干活手、脚刀具、夹具、辊筒、活塞、机械手
控制决定什么时候动、动多少大脑、神经传感器、阀、PLC、驱动器
支撑让所有东西待在正确的位置骨架机架、轴承、导轨、地脚

还有两个“看不见但决定寿命”的系统：密封和润滑。它们像人的皮肤和关节液，平时没人夸，坏了全是大事。

一句话记住看机器先看“五加二”：动力、传动、执行、控制、支撑，再加密封、润滑。任何一个环节出问题，整台机器都可能停。

二、动力：不是“多大功率”，是“多大劲、多快、怎么启动”

客户说“用个 5.5 千瓦电机”，这只是功率。销售要追问三件事：负载有多重、要多快、启动时是不是满负载。同样 5.5 kW，带风机和带破碎机完全是两回事。风机启动轻，破碎机启动可能堵转；电机选小了，不是跳闸，就是发热烧掉。

电机还有“转速—扭矩”的性格：普通异步电机启动扭矩不大，带重载启动要加变频器、软启动，或者换大一级。液压马达低速大扭矩，气动马达轻、快、便宜但费气。你不需要会算，但要知道“动力不是插上电就行”，要问客户“启动时吃什么负载”。

销售可以这样问“这台设备启动的时候，是空着启动，还是带着料/带着压启动？启动频繁吗？要不要正反转、调速？”

为什么这跟波纹管有关？因为波纹管可能装在动力和执行之间的密封、补偿位置。动力选大了、启动冲击大，波纹管的疲劳寿命就会缩短；客户只换波纹管，不解决冲击，换多少次都坏。

三、传动：减速，其实是在“用转速换劲”

电机转得快、劲小；机器要的往往是转得慢、劲大。中间的减速机、齿轮、皮带，就是在做一件事：用转速换扭矩。转速降一半，理论上扭矩翻一倍（忽略损失）。这不是玄学，是能量守恒。

常见传动有四种性格：

  • 齿轮：准、紧、效率高，但怕脏、怕冲击、怕中心距不对。齿轮一响，先看润滑和装配，不要先怪齿轮。
  • 皮带：便宜、能吸振、过载会打滑，适合远距离；但会伸长、怕油、怕高温，打滑不一定是坏事，可能是它救了你。
  • 链条：能拉、耐糙，适合低速重载；但会松、会响，需要张紧和润滑。
  • 联轴器：把两根轴连起来，同时容忍一点点偏心。偏心大、安装差，联轴器和轴承先死。
常见误判客户说“减速机漏油”，新手只换油封；老销售会看“是不是联轴器对中不好，轴被别着，油封才漏”。漏的是油，坏的是对中。

四、执行：机器到底在“干什么活”

执行机构决定客户买这台机器干什么：车、铣、钻、压、夹、搬、卷、封、测。你去看设备，不要只看铭牌，要看“最后一下”：刀具怎么切、夹具怎么夹、辊筒怎么压、机械手怎么抓。

执行环节要问三个字：力、速、准。力够不够，速度要多快，精度要多高。这三个字决定传动、支撑、控制的选型，也决定你卖的零件要不要高精度、要不要耐冲击、要不要耐高温。

记住客户说“精度不够”，不一定是控制系统问题；可能是机架刚性不够、轴承间隙大、导轨磨损、热变形。先分“控制精度”还是“机械精度”。

五、控制：让机器“知道自己在哪”

控制分两种：开环和闭环。开环是“我命令你走 10 毫米，走没走到我不管”；闭环是“我测量你走到哪，再修正”。数控机床、机器人、高端包装线，都是闭环；简单输送线可能开环。

传感器是控制的眼睛：位置、压力、温度、流量、力、视觉。传感器坏，机器可能“瞎走”，撞机、压坏产品。销售听到“偶发撞机”“位置不准”，要想到传感器、编码器、光栅尺，不要只想到机械。

六、支撑：机器的“骨架”决定它稳不稳

同样一台电机，装在厚铸铁底座上和装在薄铁皮架上，噪音、振动、寿命完全不同。支撑系统包括机架、地脚、轴承、导轨、丝杠。它不产生动力，但决定“动力能不能稳定地传出去”。

轴承是支撑里最典型的零件：它让轴能转，又让轴不要乱跑。轴承坏，很多时候不是轴承本身，是安装不对中、润滑不对、污染、过载。你卖轴承，不能只问型号，要问转速、负载、温度、环境、安装方式。

现场判断轴承发热：先摸温度、听声音、看润滑脂颜色。嗡嗡声可能是缺油，咔哒声可能是滚道伤，尖锐声可能是过载或游隙不对。

七、密封与润滑：最不起眼，最决定口碑

密封解决“不漏”，润滑解决“不磨”。一台机器漏油、漏气、漏真空，客户第一反应是“你们的密封不行”；但根因可能是轴偏心、表面粗糙、安装划伤、温度太高、介质不兼容。

润滑不是“加点油”，是“在正确的位置、用正确的油、加正确的量”。油多了会发热，油少了会磨，油脏了会磨粒磨损。销售如果能跟客户聊两句润滑，客户会把你当自己人。

八、把一台机器“看穿”：从负载倒推

给你一台陌生设备，不要从电机开始看，从“最后一下”开始：

  1. 它干什么活？负载多大、速度多快、精度多高？
  2. 执行机构需要多大劲、多大行程？
  3. 传动怎么把电机的高转速变成低速大扭矩？
  4. 动力够不够？启动、冲击、调速怎么处理？
  5. 控制怎么知道位置/压力/温度？
  6. 支撑能不能扛住振动、变形？
  7. 密封、润滑能不能撑住温度、介质、粉尘？

这七问走完，你就能画出一张“能量流”图：从电/气/液，到传动，到执行，到工件。客户说哪个环节坏，你就能判断“是零件问题，还是系统问题”。

九、销售视角：客户买的不是零件，是“不停机”

客户说“这个零件多少钱”，你要在心里换算成“它停一天，客户损失多少”。一台包装线停一小时可能损失几万；一台半导体设备停一天可能几十万。你的零件价格，放在停机损失面前，常常不是主要矛盾。

所以销售不要一上来拼单价，要问：这个件坏了，会影响哪一段？备件够不够？换一次要多久？你能帮客户减少停机，你就有资格谈价值。

全才销售的三句话① 我不只卖零件，我帮你看系统；② 我先问工况，再谈价格；③ 我能告诉你坏了会怎样、怎么防。

十、本课总结卡

五加二动力、传动、执行、控制、支撑 + 密封、润滑
动力三问负载多重、要多快、启动吃什么负载
传动本质用转速换扭矩；减速=增扭
执行三字力、速、准
支撑关键刚性、对中、润滑、污染
销售视角客户买的是不停机，不是单价

十一、8 道自测

1. 一台机器“站不稳”，最可能先看哪里？
  1. 电机铭牌
  2. 机架、地脚、轴承、导轨
  3. 控制柜颜色
  4. 说明书
答案：2。支撑系统决定刚性、振动和位置稳定。
2. 减速机的作用，本质是什么？
  1. 让电机变便宜
  2. 用转速换扭矩
  3. 让机器变好看
  4. 减少零件数量
答案：2。转速降下来，扭矩升上去（忽略损失）。
3. 客户说“皮带老打滑”，最先应该问什么？
  1. 皮带颜色
  2. 负载是不是变大、皮带是不是松/有油
  3. 电机品牌
  4. 机器价格
答案：2。打滑可能是过载保护，也可能是张紧/污染问题。
4. 轴承发热，下面哪个不是常见根因？
  1. 润滑不对
  2. 对中不好
  3. 污染
  4. 轴承颜色不好看
答案：4。发热看润滑、对中、游隙、负载、污染。
5. 客户说“精度不够”，销售应该先分什么？
  1. 国产/进口
  2. 控制精度还是机械精度
  3. 贵/便宜
  4. 大/小
答案：2。控制、机械、热变形、支撑刚性都可能影响精度。
6. 密封漏，可能不是密封本身，而是？
  1. 轴偏心、表面粗糙、安装划伤、温度/介质不兼容
  2. 机器颜色
  3. 说明书太薄
  4. 电压太低
答案：1。密封是系统问题，不是一圈橡胶的事。
7. 销售看一台陌生设备，最好的切入顺序是？
  1. 从电机开始
  2. 从最后一道工序/负载倒推
  3. 从价格开始
  4. 从品牌开始
答案：2。从执行和负载倒推，才能看懂能量流。
8. 客户买零件，本质上买的是什么？
  1. 金属重量
  2. 不停机、稳定产出
  3. 包装
  4. 发票
答案：2。把零件价格换算成停机损失，才有价值对话。

十二、今天的现场作业

找一台你能接触到的设备（泵、风机、机床、包装机、输送线都行），拍三张照片：全景、铭牌、最像“容易坏”的部位。然后写四句话：

  1. 它的动力是什么？
  2. 它怎么减速/变速？
  3. 它最后干什么活？
  4. 如果它停了，客户最怕什么？

写完发我。下一课我们拆“连接”：螺栓、键、花键、过盈配合——为什么机器里最便宜的零件，常常是最贵的疏忽。

这套课准备怎么走（30 课，每课 60 分钟）

不是“波纹管 30 讲”，是“机械全才 + 销售打法”。波纹管只作为密封/补偿的一个例子出现。

  1. 机械世界观（1–5）：机器五大部分、力与运动、材料、精度、失效
  2. 连接与支撑（6–10）：螺纹/螺栓、键/花键/过盈、轴承、导轨、机架
  3. 传动（11–16）：齿轮、带/链、减速机、联轴器、离合/制动、凸轮/连杆
  4. 流体动力（17–21）：泵、阀、液压、气动、密封
  5. 热与真空（22–25）：换热器、真空、压缩空气、润滑/冷却
  6. 机器与行业（26–30）：机床、机器人、输送线、工程机械、半导体设备

每一课都按今天这个密度：故事开场 → 机制讲透 → 现场判断 → 销售追问 → 常见坑 → 总结卡 → 自测 → 作业。不满意这一课的密度，后面就不铺；满意，我按这个标准把 30 课全部重写。
